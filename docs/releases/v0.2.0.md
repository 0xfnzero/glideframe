# GlideFrame v0.2.0

原生 macOS 与 Tauri macOS / Windows 客户端现在统一在 GlideFrame 开源仓库中维护。

- 两种 macOS 客户端共享录制、音轨、暂停时间轴、项目格式和视频导出实现，修复已授权仍反复提示录屏权限的问题。
- 重做 Tauri 界面，统一系统字体、配色、项目侧栏、录制设置、时间线与样式面板，并移除常驻诊断文字。
- 对齐区域框选、裁剪、背景、画面比例、留白、圆角、自动运镜和批量格式转换，支持两版互开项目。
- 增加明确的“打开全部录制文件夹”“打开视频文件夹”和“打开导出文件夹”入口。
- 加入 macOS / Windows 构建与 Windows 安装、录制、暂停、继续、保存、导出的 CI 工作流。

## 安装包

- `GlideFrame-v0.2.0-macOS-arm64.dmg`：SwiftUI 原生版。
- `GlideFrame-Desktop-v0.2.0-macOS-arm64.dmg`：Tauri 版。
- `SHA256SUMS.txt`：安装包 SHA-256 校验值。

两个安装包均面向 Apple Silicon、macOS 14 及以上。录制与项目导出不需要外部 FFmpeg；独立格式转换需要本机安装 FFmpeg / ffprobe（例如 `brew install ffmpeg`）。

## 验证与范围

本机通过 Swift 18 项、Rust 22 项、API 2 项测试以及 TypeScript 检查。两种已安装的 macOS 应用已验证屏幕 / 区域录制、暂停与继续、保存、项目互开、编辑、播放与导出。

Windows 后端通过编译检查，安装与录制测试工作流已提供；本次未在 Windows 主机运行该流程，因此 Release 不附带 Windows 安装包。Windows 摄像头入口暂未开放。

macOS 安装包使用 Apple Development 签名，尚未经过分发公证。

---

Native macOS and Tauri macOS / Windows clients now live in one open-source repository. This release shares the macOS recording/export core, fixes recording identity and permission handling, aligns the editing UI and workflows, and adds clear actions to locate saved videos. Downloads include the two Apple Silicon macOS applications; a Windows installer is not included in this release.

# Code of Conduct

GlideFrame aims to be a practical, respectful, and focused open source project.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent while staying clear about technical risks.
- Keep discussions focused on the project and its users.
- Welcome contributors with different experience levels.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without permission.
- Repeated off-topic disruption.
- Misrepresenting unofficial forks, builds, services, or distributions as official GlideFrame releases.

## Reporting

For sensitive issues, use the security contact process described in `docs/SECURITY.md`. For ordinary moderation problems, open a GitHub issue or contact the maintainers through the official community channels.

Maintainers may remove comments, close issues, restrict participation, or take other reasonable action to keep the project healthy.
